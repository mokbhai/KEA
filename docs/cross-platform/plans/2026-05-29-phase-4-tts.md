# Cross-Platform Rewrite — Phase 4 (Text-to-Speech) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Read selected text aloud on macOS, Windows, and Linux. Implement OpenAI text-to-speech in `core::speech` (synthesize encoded audio bytes via the `/audio/speech` endpoint), add audio playback to `platform::audio` using `rodio` (decode mp3/wav and play), extend `Settings` with `tts_voice`/`tts_model`, and wire a `speak_selection` Tauri command (selection capture → synthesize → playback) with a `tts:state` event stream, a settings UI section, and a tray + hotkey entry point.

**Architecture:** Building on Phases 0–3. `core::speech` already declares the TTS contracts (`TtsRequest`, `TextToSpeech`, `OpenAiTts`) from CONTRACTS.md — this phase **implements** them: `OpenAiTts::new` plus `TextToSpeech::synthesize` issuing a `reqwest` POST and returning the encoded audio bytes (core stays runtime-agnostic; the trait is `async`). `platform::audio` (created Phase 2 for capture) gains the `AudioPlayback` trait and `new_audio_playback` factory backed by `rodio`, decoding the returned bytes and playing them on the default output device. `src-tauri` owns `tokio` and wires the flow: `TextIo::capture_selection` (Phase 1) → `OpenAiTts::synthesize` → `AudioPlayback::play_bytes`, emitting `tts:state` Tauri events. The web UI gains a voice/model section and the tray gains a "Speak selection" item; the speech hotkey from `Settings` is reused as the read-aloud trigger.

**Tech Stack:** Rust (edition 2021), `async-trait`, `reqwest` (features `["json","rustls-tls"]`), `serde`/`serde_json`, `thiserror`, `tokio` (in `src-tauri` only), `rodio` (playback), Tauri 2.x, React 18 + TypeScript + Vite.

**Reference spec:** `docs/cross-platform/2026-05-29-cross-platform-rewrite-design.md` (Phase 4); contracts: `docs/cross-platform/plans/CONTRACTS.md`.

mod tts_tests {
    use super::*;
    use std::io::{Read, Write};
    use std::net::TcpListener;
    use std::thread;

    /// Spawns a one-shot HTTP server that returns `status`/`body`, captures the
    /// raw request, and yields the bound base URL (e.g. "http://127.0.0.1:PORT").
    fn stub_server(status: u16, content_type: &str, body: Vec<u8>) -> (String, thread::JoinHandle<String>) {
        let listener = TcpListener::bind("127.0.0.1:0").unwrap();
        let base_url = format!("http://{}", listener.local_addr().unwrap());
        let reason = if status == 200 { "OK" } else { "ERR" };
        let header = format!(
            "HTTP/1.1 {status} {reason}\r\nContent-Type: {content_type}\r\nContent-Length: {}\r\nConnection: close\r\n\r\n",
            body.len()
        );
        let ct = content_type.to_string();
        let _ = ct;
        let handle = thread::spawn(move || {
            let (mut socket, _) = listener.accept().unwrap();
            let mut buf = [0u8; 4096];
            let n = socket.read(&mut buf).unwrap();
            let request = String::from_utf8_lossy(&buf[..n]).to_string();
            socket.write_all(header.as_bytes()).unwrap();
            socket.write_all(&body).unwrap();
            socket.flush().unwrap();
            request
        });
        (base_url, handle)
    }

    #[tokio::test]
    async fn synthesize_posts_to_audio_speech_and_returns_bytes() {

            .unwrap();

use serde::{Deserialize, Serialize};

#[derive(Debug, Clone, PartialEq)]
pub struct TtsRequest {
    pub text: String,
    pub voice: String,
    pub model: String,
}

#[async_trait::async_trait]
pub trait TextToSpeech: Send + Sync {
    /// Returns encoded audio bytes (e.g. mp3) for the requested text.
    async fn synthesize(&self, request: TtsRequest) -> Result<Vec<u8>, SpeechError>;
}

/// OpenAI (and OpenAI-compatible) text-to-speech over the `/audio/speech` endpoint.
pub struct OpenAiTts {
    api_key: String,
    base_url: String,
    http: reqwest::Client,
}

impl OpenAiTts {
    pub fn new(api_key: String, base_url: String) -> Self {
        Self {
            api_key,
            base_url,
            http: reqwest::Client::new(),
        }
    }
}

#[derive(Serialize)]
struct SpeechBody<'a> {
    model: &'a str,
    voice: &'a str,
    input: &'a str,
}

#[derive(Deserialize)]
struct ApiError {
    error: ApiErrorDetail,
}

#[derive(Deserialize)]
struct ApiErrorDetail {
    message: String,
}

#[async_trait::async_trait]
impl TextToSpeech for OpenAiTts {
    async fn synthesize(&self, request: TtsRequest) -> Result<Vec<u8>, SpeechError> {
        let url = format!("{}/audio/speech", self.base_url.trim_end_matches('/'));
        let body = SpeechBody {
            model: &request.model,
            voice: &request.voice,
            input: &request.text,
        };

        let response = self
            .http
            .post(&url)
            .bearer_auth(&self.api_key)
            .json(&body)
            .send()
            .await
            .map_err(|e| SpeechError::Network(e.to_string()))?;

        let status = response.status();
        if !status.is_success() {
            let text = response
                .text()
                .await
                .unwrap_or_else(|e| e.to_string());
            // Surface the API's message when present; otherwise the raw body.
            let detail = serde_json::from_str::<ApiError>(&text)
                .map(|e| e.error.message)
                .unwrap_or(text);
            return Err(SpeechError::Http(status.as_u16(), detail));
        }

        let bytes = response
            .bytes()
            .await
            .map_err(|e| SpeechError::Network(e.to_string()))?;
        Ok(bytes.to_vec())
    }
}
```
Note: the error test posts `{"error":"bad key"}` (a plain string), so the
`ApiError` parse fails and the impl falls back to the raw body — which still
`contains("bad key")`, satisfying the assertion.

use std::io::Cursor;

/// Plays encoded audio (mp3/wav) bytes on the default output device.
pub trait AudioPlayback: Send + Sync {
    fn play_bytes(&self, audio: &[u8]) -> Result<(), AudioError>;
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum AudioKind {
    Mp3,
    Wav,
    Unknown,
}

/// Best-effort container detection from leading magic bytes. Pure + total: any
/// input (including very short slices) returns a value without panicking.
pub fn audio_kind(bytes: &[u8]) -> AudioKind {
    if bytes.len() >= 3 && &bytes[..3] == b"ID3" {
        return AudioKind::Mp3;
    }
    if bytes.len() >= 2 && bytes[0] == 0xFF && (bytes[1] & 0xE0) == 0xE0 {
        return AudioKind::Mp3;
    }
    if bytes.len() >= 12 && &bytes[..4] == b"RIFF" && &bytes[8..12] == b"WAVE" {
        return AudioKind::Wav;
    }
    AudioKind::Unknown
}

/// `rodio`-backed playback. Opens the default output stream per call and blocks
/// until the decoded source finishes, so callers should invoke off the UI
/// thread (the Tauri command runs it on a blocking task).
pub struct RodioPlayback;

impl AudioPlayback for RodioPlayback {
    fn play_bytes(&self, audio: &[u8]) -> Result<(), AudioError> {
        let (_stream, handle) = rodio::OutputStream::try_default()
            .map_err(|e| AudioError::Playback(e.to_string()))?;
        let sink = rodio::Sink::try_new(&handle)
            .map_err(|e| AudioError::Playback(e.to_string()))?;
        // `audio_kind` is informational; rodio's Decoder sniffs the format itself.
        let _kind = audio_kind(audio);
        let cursor = Cursor::new(audio.to_vec());
        let source = rodio::Decoder::new(cursor)
            .map_err(|e| AudioError::Playback(e.to_string()))?;
        sink.append(source);
        sink.sleep_until_end();
        Ok(())
    }
}

pub fn new_audio_playback() -> Result<Box<dyn AudioPlayback>, AudioError> {
    Ok(Box::new(RodioPlayback))
}
```

- [ ] **Step 2: Add the `speak_selection` command**

In `app/src-tauri/src/commands.rs`, add imports and the command. It reads
settings + the OpenAI key, captures the selection, synthesizes, then plays back
on a blocking thread, emitting `tts:state` at each stage. The
`tts:state` payload is `{"state": "<capturing|synthesizing|playing|done|error>",
"message": "<optional>"}`:
```rust
use serde::Serialize;
use tauri::{AppHandle, Emitter};
use vox_core::secrets::{KeyringStore, SecretStore};
use vox_core::speech::{OpenAiTts, TextToSpeech, TtsRequest};
use vox_platform::audio::new_audio_playback;
use vox_platform::textio::new_text_io;

#[derive(Serialize, Clone)]
struct TtsState {
    state: &'static str,
    #[serde(skip_serializing_if = "Option::is_none")]
    message: Option<String>,
}

fn emit_tts(app: &AppHandle, state: &'static str, message: Option<String>) {
    let _ = app.emit("tts:state", TtsState { state, message });
}

#[tauri::command]
pub async fn speak_selection(app: AppHandle) -> Result<(), String> {
    let settings = store().load().map_err(|e| e.to_string())?;
    let api_key = KeyringStore
        .get("openai")
        .map_err(|e| e.to_string())?
        .ok_or_else(|| "OpenAI API key is not set".to_string())?;

    // 1) Capture the current selection.
    emit_tts(&app, "capturing", None);
    let text = new_text_io()
        .map_err(|e| e.to_string())?
        .capture_selection()
        .map_err(|e| e.to_string())?;
    let text = text.trim().to_string();
    if text.is_empty() {
        emit_tts(&app, "error", Some("no text selected".to_string()));
        return Err("no text selected".to_string());
    }

    // 2) Synthesize encoded audio bytes.
    emit_tts(&app, "synthesizing", None);
    let tts = OpenAiTts::new(api_key, settings.openai_base_url.clone());
    let audio = tts
        .synthesize(TtsRequest {
            text,
            voice: settings.tts_voice.clone(),
            model: settings.tts_model.clone(),
        })
        .await
        .map_err(|e| {
            emit_tts(&app, "error", Some(e.to_string()));
            e.to_string()
        })?;

    // 3) Play back. rodio is blocking, so run it off the async runtime.
    emit_tts(&app, "playing", None);
    let play = tokio::task::spawn_blocking(move || {
        let playback = new_audio_playback().map_err(|e| e.to_string())?;
        playback.play_bytes(&audio).map_err(|e| e.to_string())
    })
    .await
    .map_err(|e| e.to_string())?;

    match play {
        Ok(()) => {
            emit_tts(&app, "done", None);
            Ok(())
        }
        Err(e) => {
            emit_tts(&app, "error", Some(e.clone()));
            Err(e)
        }
    }
}
```
(`store()`, `KeyringStore`, and `settings.openai_base_url` already exist from
Phases 0–1.)
